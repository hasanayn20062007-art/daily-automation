# Automation with Python

A simple Python-based daily automation project that sends scheduled reminder emails using Gmail and GitHub Actions.

## 🚀 Features

- Sends automated daily reminder emails
- Runs automatically at scheduled times
- Uses Python for the automation logic
- Uses Gmail SMTP to send emails
- Uses GitHub Actions for cloud-based scheduling
- No need to keep your computer running
- Credentials are securely stored using GitHub Secrets
